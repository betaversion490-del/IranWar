# 🎮 بازی بزرگ خاورمیانه | ایران در برابر آمریکا و اسرائیل

> یک بازی استراتژیک تعاملی بر اساس تاریخچه واقعی مناسبات و درگیری‌های ایران، آمریکا و اسرائیل از ۱۹۵۳ تا امروز.

## 🌐 سایت بازی

سایت تبلیغاتی بازی در GitHub Pages:
**https://betaversion490-del.github.io/IranWar/**

## 🎯 درباره بازی

شما نقش ایران را بازی می‌کنید و باید در ۸ نوبت، تصمیمات استراتژیک بگیرید که آینده منطقه را شکل می‌دهد. هر تصمیم می‌تواند به صلح، جنگ، بمب اتم، یا تغییر رژیم ختم شود.

## ✨ ویژگی‌ها

- 📜 **۱۷ رویداد تاریخی واقعی** از ۱۳۳۲ تا ۱۴۰۳ با تاریخ دقیق شمسی
- 📚 **منابع معتبر ایرانی**: تسنیم، فارس، ایسنا، مرکز پژوهش‌های مجلس، اندیشکده روابط بین‌الملل

- 🏁 **۱۰ پایان محتمل** با احتمال واقعی و مبنای تاریخی
- 🤖 **هوش مصنوعی دشمن** واکنش‌گرا
- ⚡ **سیستم کمبو و پادکارت**
- 💎 **سیستم الیکسیر** (مثل Clash Royale)

## 🛠️ تکنولوژی‌ها

- **Next.js 16** با App Router
- **TypeScript** برای type safety
- **Tailwind CSS 4** برای استایل
- **Zustand** برای state management
- **Framer Motion** برای انیمیشن
- **Vazirmatn** فونت فارسی

## 📊 منابع داده

### منابع ایرانی
- تسنیم (۱۴۰۵/۰۲/۲۱): پنج سناریوی پیش روی آمریکا در جنگ با ایران
- تسنیم (۱۴۰۵/۰۴/۲۶): کالبدشکافی یک سناریوی جنگ ترکیبی
- خبرآنلاین (۱۴۰۵): تفاهم برباد رفته / پنج سناریو
- فرارو (۱۴۰۵/۰۴): جنگ به کدام سو می‌رود؟ سه سناریو
- رسانا (Rasanah): آینده ایران در خاورمیانه
- اندیشکده روابط بین‌الملل (irthink): پرونده هسته‌ای ایران
- SID: قابلیت بازدارندگی هسته‌ای ایران
- تابناک (۱۴۰۵): قدرت بازدارنده هسته‌ای
- ایسنا (۱۴۰۵): سناریوهای بروکینگز
- مرکز پژوهش‌های مجلس: پایش فضای سرمایه‌گذاری

### منابع بین‌المللی
- IAEA: گزارش‌های فصلی بازرسی
- UN Security Council Resolution 2231
- IMO (سازمان بین‌المللی دریانوردی)
