درباره بازی

📜

مبتنی بر تاریخ واقعی

۱۷ رویداد تاریخی از کودتای ۲۸ مرداد ۱۳۳۲ تا سقوط دولت بشار اسد در ۱۸ آذر ۱۴۰۳، تماماً با تاریخ دقیق شمسی.

📚

منابع معتبر ایرانی

تحلیل‌ها بر اساس منابع رسمی ایرانی: تسنیم، فارس، ایسنا، IRNA، مرکز پژوهش‌های مجلس، اندیشکده روابط بین‌الملل، SID.

🎴

۶۰+ کارت استراتژیک

۲۰ کارت ایران، ۱۵ کارت آمریکا، ۱۵ کارت اسرائیل، ۸ کارت عربی، ۵ کارت ناتو، ۵ کارت متحدان شرقی - همه با داده واقعی.

🏁

راه‌های برد

۴ مسیر برد و ۲ مسیر باخت. هر مسیر با استراتژی مشخص و دنباله کارت‌ها.

🥇 برد - نوبت ۷

مسیر بمب اتم

خروج از NPT → افزایش غنی‌سازی → ساخت بمب. مسیر خطرناک اما قطعی.

iran_npt_withdraw → patience → china → russia → nuclear_breakout
🥈 برد - نوبت ۳

مسیر صلح جامع

دیپلماسی مداوم + صبر استراتژیک. سریع‌ترین مسیر برد.

diplomacy → patience → diplomacy
🥉 برد - نوبت ۴

مسیر خروج آمریکا

ائتلاف با روسیه و چین + فعال‌سازی محور مقاومت + کنترل جنگ.

russia → china → hezbollah → patience
🏅 برد - نوبت ۵

مسیر انزوای اسرائیل

فعال‌سازی کامل محور مقاومت + حمله موشکی.

hezbollah → houthi → iraq_militias → missile → patience
💀 باخت - نوبت ۶

تهاجم بی‌رویه

اگر فقط کارت‌های تهاجمی بازی کنید، جنگ از کنترل خارج می‌شود.

hezbollah → hormuz → missile → houthi → ...
🔥 باخت - نوبت ۴

فروپاشی اقتصادی

بستن هرمز + سلاح نفت = نابودی اقتصاد و تغییر رژیم.

hormuz → oil_weapon → hormuz → oil_weapon
